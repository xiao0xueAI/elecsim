# ElecSim 可视化编辑器

不用写代码，直接改网站。

## 启动方法

```bash
python3 admin/server.py
```

然后浏览器打开 **http://localhost:8766/**

## 能改什么

| 页面 | 能改 |
|---|---|
| 🎨 外观样式 | 27 个颜色变量（背景/边框/文字/主色/分类色） |
| 🔌 元件库 | 元件名称、图标、描述、尺寸、图片 |
| 📡 产品库 | QIACHIP 产品名称、型号、描述、图片 |
| 📐 电路模板 | 模板名称、图标、描述 |
| 🖼 图片资源 | 上传/查看所有图片 |
| 📝 代码编辑 | 直接编辑源文件（高级） |
| 👁 网站预览 | iframe 实时预览 |

## 改完怎么保存

1. 在某个页面点修改
2. 点 **"💾 保存"** 按钮
3. 切到 **"👁 网站预览"** 标签 → 刷新 → 看效果

## 改完怎么发布到网站

```bash
python3 deploy.py
```

## 注意

- **改图片**：先到「图片资源」上传，再去「元件库」/「产品库」选
- **新增功能**（按钮、菜单、仿真逻辑）：这个改不了，需要写代码，让我来
- **每次保存会自动备份**（`.bak` 文件），可以手动恢复
